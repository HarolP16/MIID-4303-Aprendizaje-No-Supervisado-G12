# Entrega Taller 01 - Grupo 12

Archivo principal: `Taller_01_Donde_abrir_nueva_sede_G12.ipynb`.

## Estructura reproducible

```text
entrega-taller-01/
|-- Taller_01_Donde_abrir_nueva_sede_G12.ipynb
|-- data/
|   `-- lugares.csv
|-- resultados/
|   `-- archivos CSV reproducidos por el cuaderno
`-- requirements.txt
```

Abra el cuaderno desde esta carpeta y ejecute `Restart & Run All`. El código carga `data/lugares.csv` y genera siete tablas en `resultados/`.

Los datos son de 1985; el resultado es un primer filtro para *due diligence*, no una recomendación vigente.
